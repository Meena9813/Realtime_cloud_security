
# Real-Time AI-Based Cloud Security Project

This project simulates a real-time AI-based anomaly detection system for cloud storage activity in e-commerce. It uses the Isolation Forest algorithm to identify unusual behavior, such as data theft or unauthorized access.

## How It Works
- Simulated cloud activity data mimics login attempts, file access, and data transfer patterns.
- The Isolation Forest model detects anomalies in near real-time.
- Visualization is provided to show anomaly clusters.

## Setup Instructions
1. Install Python 3.x
2. Install required libraries:
   pip install pandas numpy matplotlib seaborn scikit-learn
3. Run the script:
   python ai_cloud_realtime_monitor.py

## Use Case
Ideal for demonstrating AI-driven cloud security in academic, research, or prototype development scenarios.
